# Портфолио веб-разработчика

Качественное портфолио со светлой темой, реальными изображениями и кликабельными проектами.

## Проекты
1. Лендинг онлайн-школы английского
2. Сайт репетитора по математике
3. Лендинг ремонтной компании (с калькулятором)
4. Мини интернет-магазин (с корзиной и фильтрами)
5. Лендинг для психолога
6. Сайт кафе / ресторана

## Как опубликовать на GitHub Pages

1. Создай репозиторий на github.com (Public)
2. Загрузи все файлы из этой папки
3. Settings → Pages → Source: main / (root) → Save
4. Через 1–2 минуты сайт будет доступен по адресу:
   https://твой-логин.github.io/название-репозитория

## Важно перед публикацией
В index.html замени:
- @your_username → свой Telegram
- your.email@example.com → свой email
