# Портфолио веб-разработчика (светлая тема)

Готовое портфолио для старта на фрилансе.

## Что внутри

- `index.html` — главный сайт-портфолио (светлая тема)
- `styles.css` — стили
- `script.js` — небольшой скрипт
- `projects/` — демо-проекты:
  - `landing-school.html` — лендинг онлайн-школы
  - `tutor-site.html` — сайт репетитора
  - `repair-landing.html` — лендинг ремонтной компании (с калькулятором)
  - `mini-shop.html` — мини-магазин с корзиной и фильтрами
  - `psychologist.html` — лендинг для психолога

## Как загрузить на GitHub и опубликовать (пошагово)

### Шаг 1. Создай аккаунт на GitHub
1. Зайди на https://github.com
2. Нажми **Sign up**
3. Зарегистрируйся (можно через email)

### Шаг 2. Создай новый репозиторий
1. После входа нажми зелёную кнопку **New** (или + → New repository)
2. Repository name: например `portfolio`
3. Поставь галочку **Public**
4. **Не** ставь галочки "Add a README file" и другие
5. Нажми **Create repository**

### Шаг 3. Загрузи файлы
Есть два простых способа:

#### Способ А — через сайт GitHub (самый простой)
1. На странице нового репозитория нажми **uploading an existing file**
2. Перетащи **всю папку portfolio** (или все файлы внутри неё) в окно браузера
3. Внизу напиши Commit message: `first commit`
4. Нажми **Commit changes**

#### Способ Б — через GitHub Desktop (удобнее)
1. Скачай GitHub Desktop: https://desktop.github.com
2. Войди в свой аккаунт
3. File → Add local repository → выбери папку portfolio
4. Нажми Publish repository

### Шаг 4. Включи GitHub Pages
1. В репозитории зайди в **Settings** (вкладка сверху)
2. В левом меню найди **Pages**
3. В разделе **Source** выбери:
   - Branch: `main`
   - Folder: `/ (root)`
4. Нажми **Save**
5. Подожди 1–2 минуты
6. Обнови страницу — появится ссылка вида:
   `https://твой-логин.github.io/portfolio`

Готово! Это и есть ссылка на твоё портфолио.

## Что обязательно поменять перед публикацией

1. В файле `index.html` замени:
   - `@your_username` → свой Telegram
   - `your.email@example.com` → свой email
2. По желанию поменяй название "WebDev" на своё имя или ник.
